# 🎬 Filmorate

**Filmorate** — это backend-сервис для работы с фильмами, пользователями и их оценками.  
Сервис помогает составлять рейтинг фильмов на основе пользовательских лайков, формировать рекомендации и объединять людей в сообщество.

## 📌 О проекте

Современный выбор фильма часто превращается в проблему: слишком много контента и противоречивых оценок.  
Filmorate решает эту задачу: хранит информацию о пользователях и фильмах, позволяет оставлять оценки и лайки, а также формирует список самых популярных фильмов.

Приложение построено на **Spring Boot** и использует **H2 Database** для хранения данных.  
Все данные можно получать и обрабатывать через REST API.

## ✨ Функциональность

- Управление пользователями:
  - регистрация и редактирование профиля
  - добавление и удаление друзей
  - получение списка друзей и общих друзей

- Управление фильмами:
  - добавление и редактирование фильмов
  - валидация данных (описание, дата выхода, продолжительность)
  - постановка и снятие лайков
  - получение списка популярных фильмов

- Работа с жанрами и рейтингами (MPA):
  - получение всех жанров и рейтингов
  - получение жанра или рейтинга по идентификатору

- REST API с поддержкой корректных HTTP-кодов:
  - `400` — ошибка валидации
  - `404` — объект не найден
  - `500` — внутренняя ошибка сервера

- Хранение данных:
  - In-memory (для быстрого запуска и тестов)
  - H2 Database (для рабочего режима)

- Тестирование:
  - Unit-тесты и интеграционные тесты (JUnit 5)
  - Проверка работы DAO через @JdbcTest
